The tag a block carries is set here. The Coinbase tag above is the name explorers show; the primary tag below is what the block is stamped with when you do not use a pool. Every change here restarts the Gateway for a few seconds (miners reconnect by themselves).

Rule of thumb for Blake2b: floor ≈ hashrate in TH/s × 1,750, so that a machine sends about 8 shares a minute. Best check: open Clients, read the difficulty (VDiff) your smallest miner settles at, and set the floor at or just under it.

Share numbers

How every difficulty is shown: shares, best share, minimum and network difficulty, on Status, Clients and Config. The Gateway counts in hashes, the same scale as DATUM and mempool. A miner counts in units of 232 hashes, so its own number is smaller. Only the display changes, so you can switch any time.

maintenance

Restarts the DATUM Gateway process (not your Bitcoin node or Umbrel). Miners disconnect for a few seconds and reconnect on their own. Useful after a node restart or if the Gateway looks stuck.
